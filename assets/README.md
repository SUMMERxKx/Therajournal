# Assets Directory

This directory contains the app assets like icons and splash screens.

## Required Assets

- `icon.png` - App icon (1024x1024)
- `splash.png` - Splash screen (1242x2436)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon (16x16)

## Creating Assets

You can use Expo's asset generation tools:

```bash
npx expo install expo-image-utils
npx expo prebuild
```

Or create them manually with your preferred design tool.
